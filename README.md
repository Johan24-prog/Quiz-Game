# Quiz Game

Ett enkelt quizspel som körs direkt i webbläsaren. Spelet innehåller fem flervalsfrågor om bland annat geografi, rymden, programmering och kemi. Välj ett svar för att se vilket alternativ som var rätt, följ poängen och gör quizet igen från resultatsidan.

## Om projektet

Det här var ett fritidsprojekt som jag gjorde för att det var kul och för att öva på webbutveckling. Projektet gav mig möjlighet att träna på HTML, CSS och JavaScript, bland annat på att uppdatera sidan dynamiskt och hantera användarens svar.

## Teknik

- HTML för sidans struktur
- CSS för utseende och responsiv layout
- JavaScript för frågor, poängräkning och quizflöde

## Kom igång

Inga installationer behövs. Klona eller ladda ner projektet och öppna `index.html` i en webbläsare.

## Projektfiler

- `index.html` – sidans innehåll och vyer för start, quiz och resultat
- `style.css` – layout och utseende
- `script.js` – frågor och spelets funktionalitet
